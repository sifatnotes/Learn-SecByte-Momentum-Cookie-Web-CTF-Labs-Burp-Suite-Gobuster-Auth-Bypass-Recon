# Learn SecByte Momentum & Cookie Web CTF Labs

These labs are useful for **cybersecurity students, CTF players, pentesters, SOC analysts, and security learners** practicing web application security concepts in authorized lab environments.

## Introduction

This repository indexes Learn SecByte CTF labs covering practical areas of **web security, ethical hacking, penetration testing, reconnaissance, authentication, session and cookie analysis, and web enumeration**.

The repository is intended as a searchable learning reference rather than a collection of exploit answers or leaked challenge solutions.
